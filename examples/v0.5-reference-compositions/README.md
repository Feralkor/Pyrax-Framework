# V0.5 Reference Compositions

These files prove that Pyrax can recreate representative product shapes from reusable profiles and composition contracts without copying prior product implementations.

Included references:
- `route-engineer.solution.yaml` — fleet/route decision intelligence.
- `asset-radar.solution.yaml` — asset visibility and telemetry confidence.
- `predictive-maintenance.solution.yaml` — condition and intervention prioritization.
- `oee-intelligence.solution.yaml` — industrial/OEE performance intelligence.
- `decision-engine.solution.yaml` — generic evidence-backed decision support.

## What these references are

They are composition examples:

`Profile + Blocks + Adapters + UI Components + Domain Overrides`

They demonstrate reusable product structure.

## What they are not

They are not certified Domain Packs, customer deployments, or copies of the original products. They intentionally omit customer-specific semantics, credentials, contracts, source mappings and proprietary implementation details.

A real deployment must still perform discovery, data mapping, semantic certification, Golden Cases, reconciliation, integration tests and readiness assessment.
